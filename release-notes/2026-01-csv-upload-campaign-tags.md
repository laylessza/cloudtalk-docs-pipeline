## What changed
When importing contacts from a CSV file, you can now set campaign tags
(more than one per contact) and a preferred agent for each contact during
the upload itself.

## What it means for customers
Teams that import contacts by file no longer need to split their files or
fix tags and agent assignments afterwards. This speeds up campaign setup.
